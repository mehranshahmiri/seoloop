Commands

Everything is one URL

Every endpoint is /<check>/<domain>. Short answers by default, full detail as JSON.

/audit/example.com

Full audit

26 checks across SEO, performance, security and crawlability, rolled into a 0–100 score and a grade.

/indexable/example.com

Indexable?

A straight yes or no, with the reason: noindex, robots.txt, canonical, status.

/links/example.com

Broken links

Checks the links on a page and lists the dead ones.

/schema/example.com

Structured data

JSON-LD types found, and which required properties are missing.

/status/example.com

HTTP status

The final status code after following redirects.

/meta/example.com

On-page meta

Title, description, canonical, robots, Open Graph, headings, word count.

/redirects/example.com

Redirect chain

Every hop from the URL you typed to the page you land on.

/ttfb/example.com

Time to first byte

Server response time, split into DNS, connect and TLS.

/ssl/example.com

TLS certificate

Issuer, expiry, days left, protocol, trust status.

/robots/example.com

robots.txt

Fetched and parsed. Flags a site-wide Disallow: /.

/sitemap/example.com

Sitemap

Found via robots.txt or /sitemap.xml, with a URL count.

/headers/example.com

Response headers

Security headers and caching at a glance.

Get started

Use curl, or install the CLI

The CLI is a single shell script. It needs only curl.

Installcurl -fsSL https://seoloop.in/install | sh
Thenseoloop audit example.com
No installcurl seoloop.in/audit/example.com

Built for scripts

JSON, single fields, CI gates

# markdown report for a pull request
$ curl 'seoloop.in/audit/example.com?format=md'
# machine-readable
$ curl seoloop.in/v1/ssl/example.com
# one value, ready for a script
$ curl 'seoloop.in/ssl/example.com?field=days_left'
# fail the build if the score drops below 80
$ seoloop audit example.com --min 80 || exit 1
# colour in your terminal
$ curl 'seoloop.in/audit/example.com?color'
